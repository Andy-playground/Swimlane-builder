# 錯誤碼白話對照

`swimlane-builder.py lint` 和 `generate` 印出來的 `E###` / `W###` 是什麼意思、要不要理它。

英文版在 [README](../README.md#lint-codes) 的 Lint codes 一節；這份是同一張表的白話版，兩邊改了要一起改。

## E — 錯誤，圖不會產出，一定要修

| 代碼 | 白話 | 怎麼修 |
|---|---|---|
| E001 | spec 檔本身格式不對（少欄位、型別寫錯） | 照錯誤訊息補欄位 |
| E101 | 有條線連到不存在的節點 | node id 打錯了，對一下拼字 |
| E102 | 流程繞成一個圈，但沒說那是「退回重做」 | 那條回頭的線加上 `"kind": "feedback"` |
| E103 | 決策點沒寫分支條件，或只有一條出路 | 判斷至少要兩個答案，每條都要有 label |
| E104 | 有節點從起點走不到（孤島） | 通常是忘了接線進去 |

## W — 警告，圖照樣產出，你自己判斷要不要處理

| 代碼 | 白話 | 怎麼處理 |
|---|---|---|
| W201 | 節點文字太長，塞不進最大的方框，字會凸出來 | 縮短該節點的 label |
| W202 | 流程欄數超過預算，圖太寬 | 考慮把 SOP 拆成兩張流程 |
| W203 | 起點不在第一條泳道 | 慣例上發起者的泳道排最上面，調 lane 順序 |
| W204 | 同一泳道的同一欄擠了兩個決策點，分支線會搶同一條走道 | 給其中一個節點加 `"col": N` 挪開 |
| W205 | 只有部分節點有 `step` 編號 | 圖上號碼會混著 SOP 原編號和程式自算的；要嘛全給、要嘛全不給 |
| W206 | 你指定的 `col` 比排出來的最小值小，已自動往後挪 | 通常不用管；`col` 是下限不是固定位置 |
| W207 | 分支標籤字太多 | 只寫條件（`Yes`／`海運`），後果寫進下一個節點 |
| W208 | 標籤太寬，或找不到不壓到節點/其他標籤的位置 | 圖上真的會疊在一起；縮短標籤或給流程更多空間 |
| W209 | 在 1366×768 螢幕上看全圖時，字會小到讀不清 | 訊息會說實際字級和塞得下幾欄；縮短 SOP 或拆兩張。圖本身不會為了這個變形 |

## 常一起出現的組合

- **W204 + W208**：兩個決策點擠同一欄 → 分支標籤沒地方放 → 疊字。先修 W204，W208 常跟著消失。
- **W202 + W209**：都是「這張圖太大」的不同說法，W202 講欄數、W209 講讀不讀得清。
